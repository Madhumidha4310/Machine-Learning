# 📚 Online Education Student Performance Analysis

## 📌 About the Project

This project focuses on analyzing student performance in an online education environment. The dataset contains student demographic information, educational details, online activity, engagement levels, performance levels, and final results.

The project uses **Data Analysis, Data Visualization, and Machine Learning** techniques to identify patterns in student engagement and academic performance.

---

## 🎯 Objectives

- Analyze student performance data.
- Understand student engagement levels.
- Analyze pass rates based on engagement.
- Visualize important patterns in the dataset.
- Handle missing data.
- Apply feature scaling.
- Build a Logistic Regression model.
- Analyze the relationship between online activity and student performance.

---

## 📊 Dataset

- **Records:** 32,593
- **Features:** 14

### Main Features

- Student ID

- Highest Education
- Studied Credits

- Total Clicks
- Average Score

- Performance Level
- Risk Level
