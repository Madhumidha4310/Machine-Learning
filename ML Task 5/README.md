# Customer Churn Prediction

## 📌 Project Overview

This project predicts whether a customer is likely to leave a company (churn) using Machine Learning techniques. The model is trained on customer data and helps businesses identify customers who may discontinue their services.

## 🚀 Features

* Data preprocessing and cleaning
* Handling missing values
* Feature selection
* Data scaling using StandardScaler and MinMaxScaler
* Data visualization
* Machine Learning model training
* Customer churn prediction

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## 📊 Dataset

The project uses a customer churn dataset containing customer details such as:

* Credit Score
* Geography
* Gender
* Age
* Tenure
* Balance
* Number of Products
* Credit Card Status
* Active Member Status
* Estimated Salary
* Churn Status

## ⚙️ Steps Performed

1. Import required libraries.
2. Load the dataset.
3. Check missing values.
4. Clean and preprocess data.
5. Scale numerical features.
6. Perform data visualization.
7. Train machine learning models.
8. Predict customer churn.
9. Evaluate model performance.
